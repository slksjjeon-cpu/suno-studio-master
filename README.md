# 🎧 Antigravity 장르 변경 커버곡 스튜디오 (Genre Transformation Studio)

> **RTX 2060 (6GB VRAM) 최적화 순차 대기열 기반 AI 커버곡 & 장르 편곡 스튜디오 MVP**

---

## 새 작업 공간 / 기존 디자인 전환

- 기본 화면은 밝은 배경과 파란색 포인트의 새 작업 공간입니다. 상단 **기존 디자인 보기 / 새 디자인 보기** 버튼으로 전환하며, 선택은 브라우저에 저장됩니다.
- 새 작업 공간 상단의 **다크 모드 / 라이트 모드** 버튼으로 색상 테마를 전환할 수 있습니다. 선택은 브라우저에 저장되며 기존 디자인의 테마 설정과 별개입니다.
- **음원 불러오기 → 사운드 편집 → 완성·내보내기**의 세 화면으로 구성됩니다. 디자인 전환 중에도 곡, 구간, 배속, EQ 설정은 같은 컨트롤을 사용합니다.
- 링크를 붙여넣으면 다운로드·분석을 시작합니다. 자동 완곡 마스터링은 체크박스로 선택하며 기본값은 꺼짐입니다.
- 완곡·구간 렌더링과 다운로드는 내보내기 화면에 모았습니다. 속도·음정만 적용한 저장은 별도 접기 메뉴에 있습니다.
- 분석 리포트와 Suno 프롬프트는 불러오기 화면의 접기 메뉴에서 확인합니다. Hum Studio는 사이드 메뉴에서 엽니다.
- 저작권 참고 진단은 사이드 메뉴의 별도 화면에서 확인합니다. 비공식 음향 인식·카탈로그 검색 결과이며 공식 Content ID 판정이나 수익화 보장이 아닙니다.
- 새 레이아웃은 `static/workspace.js`, 스타일은 `static/workspace.css`에서 관리합니다. 기존 컨트롤을 복제하지 않고 이동·복원합니다.

## 🌟 주요 기능 및 워크플로우

1. **원곡 MP3 분석 및 시각화**
   - **Waveform Canvas**: 오디오 파형 시각화 및 클릭 탐색
   - **AI 분석**: BPM 감지, 원곡 키(Key) 분석, 스테레오 채널 및 길이 분석
   - **Whisper 자동 전사**: 원곡 보컬 가사를 자동으로 텍스트 추출

2. **구간 미리듣기 (Audio Slicing) 정밀 지정**
   - 원하는 하이라이트 구간(예: 10초, 15초, 20초 등)을 슬라이더 또는 원클릭 프리셋으로 지정
   - **선택 구간 원곡 청음**: 변경 전 원곡의 해당 구간을 바로 청음 가능

3. **가사 스튜디오 (Lyrics Studio)**
   - **사용자 커스텀 가사 입력창**: 원곡과 가사가 달라져도 사용자가 입력한 가사를 최우선으로 가창에 반영
   - **원곡 가사 자동 감지 폴백**: 가사 입력창이 비어있으면 Whisper가 추출한 원곡 가사를 그대로 가창
   - **원곡 가사 복사하기**: 한 번의 클릭으로 원곡 가사를 에디터로 가져와 일부만 수정 가능

4. **장르 편곡 & 보컬 스타일링**
   - **장르 프리셋 기본 제공**:
     - 🌴 시티팝 (80s City Pop)
     - ☕ 로파이 칠 재즈 (Lo-Fi Chill Jazz)
     - ⚡ 사이버펑크 신스웨이브 (Synthwave)
     - 🎸 어쿠스틱 인디 포크 (Acoustic Folk)
     - 🌙 시네마틱 네오 소울 R&B
     - 🔥 페스티벌 EDM (Bigroom / Future Bass)
   - **커스텀 프리셋 추가 및 저장**: 사용자가 원하는 장르와 프롬프트를 로컬 `presets.json`에 영구 저장
   - **세부 프롬프트 자유 입력**: 원하는 악기나 분위기를 직접 텍스트로 추가 튜닝
   - **보컬 분위기 선택**: 에어리 팝, 허스키 재즈, 레트로 신스 보코더, 내추럴 어쿠스틱 등
   - **피치(키) 및 템포 조절**: -6 ~ +6 반음, 0.8x ~ 1.3x 템포 조절

5. **AI 마스터링 스위트 (기본값 활성화)**
   - 스트리밍 표준 (-14 LUFS 모던 크리스프), 클럽 펀치 (-9.5 LUFS), 웜 빈티지 (-16 LUFS), 어쿠스틱 내추럴
   - 스테레오 폭 확장 (Mid/Side Imager), 아날로그 새츄레이션 & 소프트 클리핑 리미터

6. **순차 렌더링 대기열 (Sequential Queue) & A/B/C 시안 비교 청음실**
   - **RTX 2060 6GB 안전 설계**: 대기열에 여러 시안을 등록해도 하나씩 순차 실행되어 VRAM 초과(OOM) 방지
   - **시안 A, B, C 대기열 등록**: 파라미터를 변경하면서 순차적으로 큐에 등록 (`시안 A` -> `시안 B` -> `시안 C` 자동 넘버링)
   - **비교 청음실**: 완성된 시안들의 파라미터(장르, 보컬, 구간, 음압, 가사 적용 여부)를 비교하며 즉시 플레이어로 번갈아 청음
   - **⭐ 이 시안으로 전체 곡 렌더링**: 비교 청음 후 가장 마음에 드는 시안의 설정을 그대로 사용하여 완곡(Full Song) 렌더링 실행!

## 🚀 실행 방법

현재 서버가 백그라운드에서 실행 중입니다:
- **접속 주소**: `http://localhost:8000` (사용 중이면 `http://localhost:8001`로 자동 전환)
- 서버 시작 시 실제 선택된 포트가 콘솔에 출력되며, 브라우저가 자동으로 열립니다.
- 자동 브라우저 실행을 끄려면 `STUDIO_NO_BROWSER=1` 환경변수를 설정하세요.

수동 실행 시:
```bash
python app.py
```
