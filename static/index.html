    Google 로그인 시 '액세스 차단됨 (403: access_denied)' 오류 해결법

    Google Cloud 콘솔 앱이 '테스트 중'일 때는 등록된 테스트 사용자만 로그인할 수 있습니다:

    1. Google Cloud 콘솔 OAuth 동의 화면으로 이동합니다.
    2. 화면 아래 [테스트 사용자 (Test users)] 섹션의 [+ ADD USERS (+ 사용자 추가)] 클릭
    3. 로그인하려는 유튜브 구글 계정 이메일을 입력하고 [저장]을 누릅니다.
    4. 저장 후 위 [Google 계정 로그인] 버튼을 다시 누르면 연동이 즉시 완료됩니다! ('확인되지 않은 앱' 경고창 시 [고급] → [Studio Master(으)로 이동] 클릭)
    📖 Google Cloud 콘솔에서 무료로 Client ID 발급받는 방법 (1분 안내)
    1. Google Cloud Console에 로그인하여 프로젝트를 하나 생성합니다.
    2. [API 및 서비스] > [라이브러리]에서 'YouTube Data API v3'을 검색하여 [사용 설정]을 누릅니다.
    3. [OAuth 동의 화면]에서 외부(External) 선택 후 앱 이름 및 사용자 이메일을 입력합니다. (하단 테스트 사용자에 본인 구글 계정 필수 추가)
    4. [사용자 인증 정보] > [사용자 인증 정보 만들기] > 'OAuth 클라이언트 ID'를 누르고 애플리케이션 유형을 '데스크톱 앱' 또는 '웹 애플리케이션'으로 선택합니다.
    5. '웹 애플리케이션'의 경우 '승인된 리디렉션 URI'에 http://127.0.0.1:8000/api/youtube/oauth/callback 을 추가하고 만들기 클릭!
    6. 생성된 클라이언트의 JSON 파일을 다운로드하여 위 드롭존에 업로드하시면 즉시 연동이 완료됩니다!
